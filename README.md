# Mantenimiento de Compresores (PWA)
App offline-first: React + TypeScript + Vite + Dexie (IndexedDB).

    npm install
    npm run dev       # desarrollo
    npm run check     # tsc + lint + tests + build
    npm run preview   # probar PWA/offline sobre el build
